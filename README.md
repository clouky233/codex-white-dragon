# Codex 白龙

一个基于 Electron 的 Windows 桌面白龙挂件，用气泡查看本机 Codex 订阅额度，并在满足账号绑定条件时提示任务完成。当前版本为 **0.1.2**，属于非官方工具，与 OpenAI 无隶属关系。

- 平时只显示白龙。点击会捏脸并打开额度气泡，5 秒后收起；再次点击重新计时。
- 悬停在额度气泡上暂停关闭，移开后重新计时 5 秒。拖动只移动角色，不弹出气泡。
- 气泡底部可刷新额度、打开设置或隐藏到托盘；右键白龙也可打开设置和退出。
- 支持透明区域点击穿透、边缘吸附、缩放、翻转、置顶、六种表情和轻微动态效果。
- 提供任务完成气泡、合成提示音、本地完成记录，以及本次运行的额度趋势。

开发运行需要 **Windows x64、Node.js 22.12 或更高版本**，以及已安装并登录的 Codex。应用会尝试找到本机 Codex 可执行文件；也可通过环境变量 `CODEX_DRAGON_CODEX_PATH` 指定位置。在项目目录运行：

```powershell
npm ci
npm start
```

运行模块测试：

```powershell
npm test
```

额度由本机 Codex app-server 只读获取，每 60 秒自动刷新，也可手动刷新。未返回的额度窗口显示为未提供，不估算、不补成零，也不把 token 换算成额度扣减。百分比属于整个账号，可能受到其他会话或设备影响。

任务监控需要显式绑定并核对账号；未绑定时可查看本机 CLI 返回的额度，但不启动任务日志监控。账号不匹配时隐藏额度。绑定标识可由本机设置或 `CODEX_DRAGON_EXPECTED_ACCOUNT_ID` 提供，不应提交到仓库。完成统计来自绑定账号的本地主会话日志，缺少可靠计数时不会估算。

设置和完成记录保存在当前用户的 `%APPDATA%\CodexWhiteDragon`，登录由本机 Codex 管理。挂件不直接读取 `auth.json` 或 Cookie，不执行推理、重置额度或付费操作。设置中的通知气泡停留时间与点击查看额度的固定 5 秒分别控制。
