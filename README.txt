Codex 白龙额度挂件 0.1.2（Windows x64）

如何使用
安装后双击桌面“Codex 白龙”，或开始菜单中的同名快捷方式。
平时只显示白龙。点击白龙会捏脸并显示额度气泡，5秒后自动收起；再次点击会重新计时。
鼠标悬停在额度气泡上时暂停收起，移开后再计时5秒。拖动白龙只移动，不弹出额度气泡；靠近边缘自动吸附。
额度气泡底部的 ↻ 刷新额度，⚙ 打开设置与完成记录，− 隐藏到系统托盘。
也可右键白龙，选择“设置与记录”；右键白龙或托盘可退出。
设置里可缩放、翻转、置顶、减少动态、修改强调色、调提示音音量和低额度阈值。
设置中的气泡停留时间控制任务通知；点击查看额度的气泡固定为5秒。
应用不会设置开机自启。关闭主窗口会隐藏到托盘；退出请用右键菜单或设置页“退出白龙”。

安装位置
当前用户的 %LOCALAPPDATA%\Programs\CodexWhiteDragon。
本机设置与最多300条数字完成记录：%APPDATA%\CodexWhiteDragon。
账户绑定仅保存在本机设置中；交付源码与应用包不含账号标识或登录凭据。
可在 Windows“已安装的应用”中卸载 Codex 白龙。默认保留本机设置与记录。

已实现
1. 官方 Codex app-server 的只读实时额度；每60秒刷新，支持手动刷新与更新提示。
2. 按 windowDurationMins 解释额度窗口，显示剩余、进度、重置时间/倒计时和最后更新。
3. 支持多个限额桶、未知字段、离线、陈旧与已过重置时间；保留账号绑定与不匹配保护。
4. 六表情白龙透明悬浮窗；表情切换、轻微呼吸/思考动效、捏脸、拖动、吸附、缩放、翻转、位置保存、置顶和托盘。
5. 仅监控绑定账号的本地主会话日志中的任务开始/完成/错误；不重播启动前的旧通知。
6. 完成气泡、自动关闭、原创合成提示音、可选 Windows 通知；完成记录本地保存。
7. 有可靠累计基线时提供本轮主会话输入/输出 token；缺基线或计数异常时明确不可核验。
8. 完成后刷新额度并展示期间观察到的账号百分点变化；重置、旧快照等情况下不计算。
9. 本次运行最多180个额度观测点的趋势；跨重置边界断开连线。
10. 默认仅显示角色，按需打开额度气泡；隐藏气泡及其按钮不占用鼠标点击区域。

准确性与范围
百分比是同一账号整体的订阅限额，其他会话、设备或共享产品都可能影响它。
“账号已用上升X个百分点”不是精确的逐轮扣费，也不能由token换算而来。
本轮token来自Codex日志中的累计计数差分，包含记录到的推理累计，不包括子代理；缺失时不估算。
本地日志通常不会立即更新，完成后会短暂等待迟到计数；超过等待窗口的追加计数未必纳入完成摘要。
运行前已开始的长任务可恢复活动状态，但如果未读到可靠起始累计计数，本轮token会显示不可核验。
仅读取最近4个日期目录、最多64个会话文件；更早建立且未出现在这些目录中的会话暂不监控。
独立app-server只负责读取账号/额度；现有桌面任务事件另从本地日志观测，并非自动订阅桌面所有任务。
本机首次开发时已比较 sidecar 返回的 accountId 与桌面额度工具的 accountId，完全相同。
换电脑或切换账号后不会自动假设同一账号。未绑定时可读取本机CLI额度，但任务监控停用；不匹配则隐藏额度。
挂件代码不直接读取auth.json、Cookie，不导出访问令牌；认证由本机Codex管理，不调用推理、重置次数或付费操作。
所有统计仅本地保存；renderer没有Node权限、不加载远程网页。

仍保留的后续目标
阶段2：自定义角色/音频导入、素材与音频裁剪/预览、字体/文本/模块布局，持续保存的额度历史与更多趋势维度。
阶段3：Windows窗口跟随、多屏/不同DPI长期稳定性，以及客户端问题/审批等待事件的独立接入验证。
动画：当前为生成式六张静态表情加程序轻动效，未伪称逐帧动画。等待表情已备好，但尚未自动识别问题/审批等待。
安装与系统提示音已通过程序侧测试；长时间运行、多屏切换、Windows通知中心与实际听感仍需日常使用检验。
